# \# GeoPulse: Hyper-Local Retail Mobility Analytics

# 

# \## Project Overview

# GeoPulse is a retail mobility analytics project that uses anonymized GPS location data to understand customer movement patterns and store catchment areas.

# 

# \## Project Objectives

# \- Generate synthetic and anonymized GPS mobility data.

# \- Analyze customer movement around retail stores.

# \- Identify store catchment areas within a 500-meter radius.

# \- Calculate hourly unique store visitors.

# \- Develop insights to support retail location planning.

# 

# \## Technology Stack

# \- Python

# \- Snowflake

# \- PySpark

# \- Apache Sedona

# \- dbt

# \- SQL

# \- Geospatial Analytics

# 

# \## Project Structure

# \- data: GPS datasets and processed data.

# \- notebooks: Data analysis and experiments.

# \- src: Python source code.

# \- sql: SQL queries.

# \- dbt: Data transformation models.

# \- reports: Project reports and findings.

# 

# \## Week 1: GPS Data Generation

# The first week focuses on generating synthetic GPS ping data with DeviceID, Lat, Long, and Timestamp fields and preparing the dataset for Snowflake GEOGRAPHY storage.

# 

# \## Week 2: Spatial Analysis

# The second week focuses on 500-meter store catchment analysis using Apache Sedona and PySpark, followed by hourly unique visitor modelling with dbt.

#
